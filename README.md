# VAJRA --- Bharat Command Network

### AI-Powered Defense Command & Decision Support System

**Team:** HEXAVAULT\
**Hackathon:** Smart India Hackathon (SIH) --- Final Prototype

> **From Sensor to Situation. From Situation to Decision.**

VAJRA is a secure command and decision-support prototype designed to
bring operational information into **one unified view**.

We are not building another dashboard.\
**We are building a single window into the operational picture.**

------------------------------------------------------------------------

## 📌 Project Overview

**VAJRA** is a defense command and intelligence platform created for the Indian Armed Forces (Army, Navy, Air Force). It combines live video feeds, biometric security, AI threat detection, and asset tracking into a single tactical dashboard to support rapid decision-making in high-stakes environments.

## 🚀 What is VAJRA?

In a defense environment, information can come from many different
sources such as surveillance feeds, sensors, incidents, intelligence,
personnel and resources.

The challenge is to make this information easy to understand and useful
for the person making the decision.

**VAJRA brings these important information areas together in one
platform.**

The prototype demonstrates:

-   Secure user registration and login
-   Multi-layer biometric verification
-   Central operational dashboard
-   Live feed monitoring
-   Threat and incident monitoring
-   AI-assisted analysis
-   Structured reports
-   Resource and asset monitoring
-   Security, notification and system settings

## 🔐 1. Secure Authentication

VAJRA starts with a secure access flow.

### Login

Authorized users can access the platform using their registered
credentials.

### New Registration

New users can create a profile by providing the required service and
identification details.

### Biometric Verification

The prototype demonstrates multiple verification layers:

-   **Iris verification**
-   **3D face verification**
-   **Voice verification**

This provides an additional security layer before the user enters the
command environment.

> The prototype demonstrates the authentication workflow. Actual
> deployment would require approved biometric hardware, security
> policies and production-grade identity infrastructure.

------------------------------------------------------------------------

## 🖥️ 2. Command Dashboard

After authentication, the user reaches the main VAJRA dashboard.

The dashboard provides a single operational view containing:

-   Operational map
-   Personnel and unit information
-   Threat summary
-   Recent incidents
-   Weather and environment information
-   Mission and system status
-   Access to all major modules

The objective is simple:

**Give the right information to the right person at the right time.**

------------------------------------------------------------------------

## 📡 3. Live Feeds

The **Live Feeds** module brings multiple types of surveillance and
sensor information into one screen.

The prototype demonstrates feeds such as:

-   CCTV
-   Drone
-   Satellite
-   Ground sensor
-   Thermal / FLIR
-   City surveillance
-   Naval / port views

Users can filter and inspect available feeds while also viewing recent
live events and the operational map.

This creates a consolidated view instead of requiring the user to switch
between separate monitoring screens.

> The feeds shown in the prototype are demonstration data/UI
> representations and are not connected to classified or real military
> systems.

------------------------------------------------------------------------

## ⚠️ 4. Threats & Incidents

The **Threats & Incidents** module focuses on operational events.

It allows the user to view:

-   Threat location
-   Severity
-   Incident status
-   Recent events
-   Geographic context
-   Threat summaries

The map helps answer two immediate questions:

**What happened?**\
**Where did it happen?**

This helps the operator understand the current operational situation
faster.

------------------------------------------------------------------------

## 🧠 5. AI Analysis

The **AI Analysis** module is the decision-support layer of VAJRA.

The prototype demonstrates:

-   Threat prediction
-   Pattern identification
-   Video and image analysis
-   AI-generated insights
-   Trend analysis
-   Predictive analytics
-   Model performance information
-   Recommendations

The key idea is not simply adding AI to surveillance.

**Our innovation is connecting intelligence to the decision-maker.**

AI is used to organize and highlight important information so that an
authorized human operator can evaluate the situation and make the final
decision.

------------------------------------------------------------------------

## 📑 6. Reports

The **Reports** module organizes operational information into structured
reports.

It is intended to make important information easier to:

-   Review
-   Track
-   Summarize
-   Share with authorized users
-   Refer to during decision-making

This helps convert ongoing operational activity into information that
can be reviewed later.

------------------------------------------------------------------------

## 📦 7. Resources

The **Resources** module provides a centralized view of operational
assets.

The prototype organizes information around:

-   Personnel
-   Combat units
-   Equipment
-   Aircraft
-   Ships
-   Supply levels
-   Unit deployment
-   Infrastructure
-   Supply and logistics

A resource map provides geographical context for the displayed assets.

The goal is to give the decision-maker a quick understanding of **what
is available, where it is, and its current status**.

------------------------------------------------------------------------

## ⚙️ 8. Settings & Security

The **Settings** section provides centralized configuration for the

It includes areas such as:

-   User profile
-   Display and UI preferences
-   Notifications

## 💡 What Makes Our Approach Different?

### 1. One operational view

Instead of separating feeds, threats, resources and analysis, VAJRA
brings them together.

### 2. Security from the entry point

The prototype begins with authentication and biometric verification
before entering the command environment.

### 3. Intelligence connected to action

AI analysis is positioned inside the operational workflow rather than as
a separate feature.

### 4. Human remains in control

VAJRA is a decision-support system. AI provides analysis and insights;
the authorized human remains responsible for the final decision.

### 5. Modular design

The platform is divided into clear modules so additional approved data
sources and services can be integrated in the future.
